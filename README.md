# G B Harish — Portfolio Website

Professional portfolio website showcasing the skills, projects, and experience of **G B Harish**, a Software Engineer and Full Stack Developer.

> **Live Demo:** [https://harishdevs.vercel.app]([https://harishdevs.vercel.app](https://harishgbs.github.io/synent-task1-portfolio-harish/))

---

## Features

- **Hero Section** — Animated introduction with availability badge, code window visual, and prominent CTA buttons
- **About Section** — Professional summary, career objective, and values with animated statistics cards
- **Education Timeline** — Chronological timeline with styled markers and hover effects
- **Experience** — Internship showcase with achievement highlights and technology tags
- **Skills** — Categorized skill tags with modern glassmorphism cards and hover animations
- **Projects** — Premium project cards with featured styling, overlays, and technology badges
- **Contact** — Functional contact form (Formspree) with social profile links and email/ location details
- **Footer** — Navigation links, social icons, and branding

## Design Highlights

- **Dark theme** with glassmorphism UI (frosted glass cards, backdrop blur)
- **Gradient accents** (purple-to-teal) for visual hierarchy
- **CSS-only animations** (fade-in, scale-in, float, shimmer dividers)
- **Responsive** across mobile, tablet, desktop, and large screens (1400px+)
- **Accessibility** — Skip link, semantic HTML, ARIA labels, focus-visible outlines, prefers-reduced-motion support
- **SEO** — Open Graph tags, Twitter cards, JSON-LD structured data, meta tags

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

```bash
# Clone the repository
git clone https://github.com/Harishgbs/synent-task1-portfolio-harish.git

# Navigate into the project directory
cd synent-task1-portfolio-harish

# Open in browser
open index.html
```

No build tools or package managers required — this is a pure HTML/CSS site.

## Deployment

### Deploy to Vercel (Recommended)

1. Push the repository to GitHub
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub
3. Click **Add New > Project**
4. Import the repository
5. Vercel auto-detects the static site — no configuration needed
6. Click **Deploy**

### Deploy to GitHub Pages

1. Go to repository **Settings > Pages**
2. Under **Branch**, select `master` and `/ (root)` folder
3. Click **Save**
4. Your site will be live at `https://harishgbs.github.io/synent-task1-portfolio-harish/`
